# instagram-agent — 13 skills de Claude Code para Instagram

Trece skills que convierten Claude Code en un equipo de contenido para Instagram:
escriben reels, carruseles, stories y captions, auditan lo ya publicado, puntúan el
perfil y limpian el rastro de IA antes de que nada se publique.

Copia mantenida por [BarmetMedia](https://barmetmedia.com) del proyecto original de
**Jake Schincariol**. Código sin modificar; solo añadimos este README.

## Instalación

```
/plugin marketplace add barmetmedia/instagram-agent-skill
/plugin install instagram-agent
```

O desde el repositorio original:

```
/plugin marketplace add Jakeschincariol/instagram-agent-skill
/plugin install instagram-agent
```

## Las 13 skills

| Skill | Qué hace |
|---|---|
| `/ig-reel` | Escribe el reel desde una idea suelta: ganchos a partir de 26 fórmulas, puntuados, y la hoja de tiempos |
| `/ig-viral` | Busca los reels que están funcionando ahora en tu nicho y los ordena por múltiplo de outlier |
| `/ig-caption` | El caption y, sobre todo, la línea que sobrevive al corte del «… más» |
| `/ig-carousel` | La portada que gana el swipe y el guion slide a slide |
| `/ig-story` | La secuencia de stories del día, frame a frame |
| `/ig-profile` | Puntúa el perfil sobre 100 con una rúbrica de 12 partes y lo reescribe |
| `/ig-audit` | Post-mortem de lo ya publicado: qué repetir y qué dejar de hacer |
| `/ig-plan` | La semana en Instagram: qué publicar, en qué formato y cuándo |
| `/ig-comment` | Comentarios en publicaciones de otros que no parecen automáticos |
| `/ig-reply` | Respuestas a los comentarios de tus propias publicaciones |
| `/ig-dm` | Mensajes directos que obtienen respuesta, con entrega por palabra clave |
| `/ig-repurpose` | Convierte un asset largo (vídeo, pódcast, directo, newsletter, artículo) en piezas |
| `/ig-human` | Quita la huella de máquina: rayas largas, muletillas de IA y frases vacías |
